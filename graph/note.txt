A graph is a data sturcture used to represent relationships between differnet entities..

it containe the node(called Vertices) and connected by links  (Called edges).

Vertices --> represent entities or object (Node).
edges --> show the conncetion b/w the two nodes.  (arrows)

types of graph

1. Directed graph
edges have a Direction ( One way conncetion)..

2. UnDirected graph
edges have no Direction(Two  way conncetion).

Weighted graph
Each edges has a value (Weight) like: distance or time etc..
let suppose google map use kar raha ho is me distance or time show when you reach the destination.. best example of Weighted graph

Unweighted graph
All edges are treated equally with no weight..
not mention any distance or cost..

// Adjacency Matrix: (it is not Memory effieient)
-> Is a 2D array used to represent a graph. 
-> Row and Columns represent Vertices.
-> if there is an edges b/w vertex i and j, the cell contains 1 (or weight)... if there is no edges, the cell contain 0.

-> Time Complexity --> 0(1) (Check edges existence)
-> Space Complexity --> 0(V^2) (expenvise hota ha in team of Spaces.)

// Adjacency List (it is Memory effieient most used in real world problems)
-> represent a graph using an array of lists
-> store only existing edges, not unnecessary data. best suited for sparse graph(Few edges)

-> Time Complexity: 0(degree of vertex)
